# Mr Roller Dude

Just a replica of the Ball Game i used to play on Poki as a child/student.

Its basically a ball rolling with the objective to reach the end aka the Flag. 
Building this brought back memories from when I used to play this in the School Computer labs.

## Controls

- A / D or Left / Right - move
- Space / W / Up - jump
- R - restart the current level

## Open

1. Extract the ZIP.
2. Open Godot 4.x.
3. Import `project.godot`.
4. Press F6/F5 to run.
